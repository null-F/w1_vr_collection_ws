# 固定中文提示音

`zh_CN/` 包含本项目 22 条固定提示音；原文在 `config/w1/voice_prompts.json`。
由 eSpeak NG 1.51 的 Mandarin 拼音发音模式 (`cmn-latn-pinyin`，显式 UTF-8 `-b 1`)以 speed=170 离线生成，不是任何具体人员的仿声，也不是原火山音色。
生成工具为 Ubuntu 包 `espeak-ng 1.51+dfsg-12build1`，仅在开发机 `/tmp` 解压使用，语言数据来自开发机已安装的数据包。
不包含合成引擎二进制或模型。每个 WAV 的原文、SHA256、时长及引擎信息见 `zh_CN/manifest.json`。

这是一套可运行的基础音色，尚未在 PC1 Yundea 音箱试听验收，不应标为“生产音质已通过”。
生成过程仅写文件，没有执行播放。运行时只读取 WAV，不需要 eSpeak NG 或网络。
更换音色请离线制作相同文案、校验并试听后整体替换，详细步骤见 `../OFFLINE_VOICE.md`。

## 已修复的英文发音问题

最初使用 `cmn` 且未显式指定输入编码，用户实际试听发现是英文。开发机复现出了与旧 WAV **逐字节相同**的文件；
发音跟踪显示汉字被转为 `shu4` 等拼音后进入 `(en)` 回退，声调数字也读成了英文词。未指定 UTF-8 时，部分中文标点还被误解为拉丁字符。
因此，中文文案和 `voice=cmn` 标签并不能证明 WAV 实际是中文；此前仅检查文案/文件格式的测试不足以发现此问题。

全部 20 个 WAV 已重新生成，清单升级为版本 2，旧版清单会被播放器拒绝，以免只更新脚本却继续使用错误音频。
生成时同一次调用输出 WAV 和音素跟踪；每条检查普通话声调标记且拒绝 `(en)` 等外语回退，再写入清单。
清单保存各条 `phonemes` 供复核。这是**发音路径检查，不是人工听感或语音识别验收**；仍请对新文件实际试听。
