# 手柄安装补偿预览

电脑浏览器界面用于独立调整左右手局部 XYZ 平移（cm）、固定轴 xyz 旋转（度），显示原始/补偿/参考坐标轴以及实际位置和变换矩阵。计算与 `ControllerOffsets` 一致：`T_corrected = T_controller @ T_offset`，旋转为 SciPy 小写 xyz，即 `Rz @ Ry @ Rx`。

## 两次采样自动标定

VR 仍接 PC1，电脑只打开页面。选择“机器人实时追踪”和待标定的左/右手：

1. 先关闭 C 跟随，正常掌心握持，固定前臂和手腕，点击“① 采集掌心参考”；约 2 秒完成，页面显示稳定度。
2. 保持手腕的位置和朝向，将手柄固定到手背；不要退出/重置 XR。点击“② 采集手背并求解”。
3. 自动计算 `T_offset = inverse(T_back) @ T_palm`，将结果填入当前手预览；检查后再点击“保存待用配置”。不会自动保存、应用或运动。
4. 左右手分别重复。手动滑块保留，可在自动结果基础上微调。

手柄应放在头显前方，距头显至少 10 cm；左右手柄坐标重合的疑似占位数据拒绝标定。每组至少 25 个独立快照，位置最大偏离均值不超过 8 mm、旋转最大偏差不超过 3°；追踪接收年龄不能超过 0.25 秒，且采样期间不能开启跟随。旋转平均使用四元数方法而非欧拉角逐项平均。掌心参考有效期 10 分钟，VR WebSocket 连接会话改变则拒绝配对。它无法检测同一连接中未上报的 XR 原点重置，也无法凭单个手柄判断两次之间手腕是否移动；必须保持该条件，不应把两组各自稳定视为准确性证明。

已求解采样及结果保存在 `runtime/offset_calibration/`，便于复核。自动标定仅允许实时追踪，演示模式不能采集。网页刷新或服务重启后需重新采掌心。

## 启动

在工程所在机器上执行（需 Python、SciPy，无外部 JS/CDN 依赖）：

```bash
python3 repos/w1_vr_glove_integration/offset_preview.py
```

本机打开 `http://127.0.0.1:18772/`。没有实时追踪时可切换“演示姿态”，演示不代表实机反馈。

若服务运行在 PC1：

```bash
ssh -N -L 18772:127.0.0.1:18772 dexforce@192.168.20.20
```

保持隧道运行，电脑浏览器仍访问 `http://127.0.0.1:18772/`。服务仅监听 PC1 回环地址，不能直接用 PC1 IP 访问。安装服务后可 `sudo systemctl start linkerhand-w1-offset-preview`；无需开启开机自启动。

## 实时预览和保存

`pedal_pose.py` 在现有单人模式位姿入口每 50 ms 最多写一份原始追踪快照到 `/run/linkerhand-w1-pedals/controller_preview.json`；写失败不影响遥操。数据来自补偿前的 WebXR 消息。预览服务仅读取该快照，不订阅控制指令、不调用 IK、不使能机器人。VR 断流超过 0.5 秒后网页停止使用旧快照。

首次接入快照发布代码需要重新加载 VR 服务。头显须进入 VR 页面、有有效手柄追踪；无需手套开启，也无需踩跟随踏板。调参前应关闭实际跟随；页面本身不会强制关闭机器人现有遥操。

滑块变化仅更新浏览器预览；“保存待用配置”校验参数、备份旧值至 `runtime/backups/controller-offset-preview/`，并原子更新 `config/w1/controller_offsets.json`。**不会热更新正在运行的遥操，不会重启服务或触发机器人运动。** 最终参数需要正常重新加载 VR 服务才生效。使用“启用补偿预览”关闭补偿后再保存，会将实际配置 enabled 一并保存为 false。

平移限制 ±50 cm、旋转限制 ±180°。镜像使用 `M=diag(-1,1,1)`：`t'=M t, R'=M R M`，对应 xyz 角 `[rx,-ry,-rz]`；左右安装不对称时应分别调整。

“记录当前原始姿态为参考”仅在当前页面保存每只手的原始位姿。可先正常握持并记录参考，再保持手腕位置与姿态移到手背，比较补偿目标与参考的距离/角度；若手腕移动或 XR 参考空间重置，比较结果不能当作准确安装偏移。切换实时/演示来源会清除参考。

服务保存接口使用页面令牌和 localhost Host 校验，不提供机器人运动或服务重启接口。

## 多组映射库

`config/w1/controller_offset_profiles/` 保存独立 JSON 映射组，刷新页面、服务重启后仍保留。升级前当前左右手配置单独归档为“当前保留组（升级前配置）”，固定显示在列表前部；新采样不会覆盖它。原参数额外备份在 `runtime/backups/controller-offset-preview/current_preserved_20261125.json`。

每次成功“采集手背并求解”会自动新增当前手采样组；可在采集前填写名称。每个新的手腕方位都应重新完成掌心/手背配对，不将同一掌心参考的反复重采当成独立多方位标定。原始双组采样仍保存在 runtime/offset_calibration，映射组中保存其关联路径与稳定度。

“归档当前左右手预览”保存一套完整左右手配置；“加载当前手”只载入选中手；完整配置组可“恢复整组”。以上操作只改变页面预览或独立归档，不改当前遥操参数。

勾选当前手的 2～30 组原始映射，点击“生成平均组并预览”：平移均值 + 四元数旋转平均，不直接平均欧拉角。平均组另行归档，保留来源组编号与逐组偏差；平均组不能再次勾选参与平均，避免重复叠加权重。不同左右手数据不能混合。

最大相对均值平移偏差超过 20 mm 或旋转偏差超过 10° 时提示检查异常组，不静默删除样本，也不保证平均后更准确；这些是排查提示阈值而非标定精度认证。确认后仍需点击“保存待用配置”，才写 controller_offsets.json；预览服务不会重启 VR 或发送运动指令。
